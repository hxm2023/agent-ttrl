## Core defect summary

1. **STATIC_SERVED_POLICY (fatal)**: the LoRA-updated HF/PEFT model on GPU0
   never became the vLLM serving policy on GPU1; every first attempt was
   generated by the static base model. Per-task "update effects" came from
   sampling-stream displacement (arms consumed different RNG draws), not
   from policy change. 96/96 naive==egc outcomes are the expected pattern
   under a static served policy, not evidence about EGC.
2. **RNG_SCHEDULE_CONFOUND**: frozen arms drew fewer generations than
   update arms with no request-scoped seeds.
3. **NON_COUNTERFACTUAL_EGC**: tau2 "egc" was a z-score threshold over
   ordinary rollouts — no decision snapshot, fixed actions, G×R matrix, or
   common random numbers.
4. **BRANCH_ACTION_IDENTITY_BREACH**: CTS (g,r) loops regenerated actions
   per continuation; credits mapped to wrong completion spans; branch
   completions trained against first-attempt prompt ids.
5. **ENV_RESET_BREACH / UNDEFINED_PROMPT_IDS**: AppWorld update rollouts
   executed after /reset (world=None) and would NameError on any nonzero
   advantage.
6. **OFFICIAL_EVAL_BYPASS**: tau2 evaluation was a custom action-overlap
   proxy, not the official dual-control loop (no user simulator /
   orchestrator / official evaluator).
7. **LEDGER_NOT_APPLIED / SPLIT_MANIFEST_BYPASS**: formal streams did not
   use the CostLedger, Guard event chain, or split role manifests.
8. **EPROCESS_COMPENSATION_ERROR**: the claimed empirical-Bernstein
   e-process used lambda^2/8 compensation for [-1,1] data (Hoeffding needs
   lambda^2/2); the supermartingale claim fails a one-line counterexample.
9. **SYNTHETIC_LABEL_REPLAY**: M4 used hand-generated Gaussian archives;
   "100% catastrophic reduction" reflects an easily separable synthetic
   label, and always-rollback also achieves zero.
10. **STATISTICS DEFECTS**: reported "two-sided" permutation p was
    computed one-sided; n=4 cannot reach the pre-registered p<0.01; the
    hierarchical bootstrap was never applied to primary results.

## What v2 fixes (policy-consistent EGC-TTRL)

- Served-policy consistency: one colocated PEFT model generates AND trains
  (runtime/served_policy.py); atomic commit + canary (adapter hash, logit
  KL, deterministic-output change); rollback.
- Request-scoped RNG (runtime/request_seed.py): production seeds never
  shift due to update-arm draws; A0 zero-LR identity test.
- CTS-v2 latent skill families + leave-one-template-out streams.
- Cross-task evidence replay buffer (optimization/replay_buffer.py).
- Exact two-sided sign-flip + hierarchical bootstrap stats (stats_v2.py).
- Correct G×R branch executor (in progress, credit/branch_executor_v2.py).

v2 runs live under `protocols/runs/v2/` and `artifacts/v2/` with the
extended manifest contract (§12.5).
