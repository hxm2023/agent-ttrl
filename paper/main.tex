\section{Introduction}
Deployment-period agents face partial, endogenous feedback. We ask whether
session-scoped parameter updates can improve future tasks without
contaminating behavior (prequential induction), and answer with a
two-scale evidence-gating mechanism: local gates decide which action tokens
produce gradient; a global gate decides which candidate adapters reach
future tasks.
